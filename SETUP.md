# SETUP — работа с проектом из облака (с любого ПК)

Как использовать этот репозиторий (скиллы, шаблоны, правила) в облаке Claude Code,
чтобы работать из браузера на любом компьютере после входа в аккаунт. Локально ничего
ставить не нужно.

---

## 0. Что потребуется
- Аккаунт Anthropic с планом **Pro / Max / Team / Enterprise** (облачные сессии Claude
  Code доступны на этих планах; на API-ключах Console — нет).
- Доступ к этому GitHub-репозиторию `kofyonerook210/GORD_PR_AGENCY` (он приватный).

## 1. Разовая настройка (10 минут)
1. Открыть **[claude.ai/code](https://claude.ai/code)** и войти в аккаунт.
2. Установить **Claude GitHub App** — по подсказке пройти OAuth в GitHub.
3. Выдать приложению доступ к репозиторию **`GORD_PR_AGENCY`** (можно выбрать
   конкретные репозитории).
4. Создать **облачное окружение (environment)**: имя — `GORD`, сеть — **Trusted**
   (по умолчанию; нужен доступ к PyPI).
5. В настройках окружения вставить **setup-скрипт** (см. §2) — он поставит зависимости,
   LibreOffice и корпоративный шрифт.
6. Выбрать репозиторий `GORD_PR_AGENCY`, запустить пробную задачу.

## 2. Setup-скрипт окружения (вставить в поле «Setup script»)
```bash
# Python-зависимости для сборки отчётов/документов
pip install -r requirements.txt
# LibreOffice + poppler — для рендера/предпросмотра pptx/pdf в Linux
sudo apt-get update -y && sudo apt-get install -y libreoffice poppler-utils fontconfig
# Корпоративный шрифт Geologica
mkdir -p ~/.local/share/fonts
cp "Шрифты (корпоративные)/"*.ttf ~/.local/share/fonts/ 2>/dev/null || true
fc-cache -f
```
> Установка LibreOffice может быть небыстрой; если упрётся в лимит времени setup —
> убрать её отсюда и ставить в начале конкретной задачи, когда нужен предпросмотр.
> Результаты setup-скрипта кэшируются и переиспользуются между сессиями.

## 3. Ежедневная работа — с любого ПК
1. Зайти на **claude.ai/code** под своим логином (любой браузер, любой компьютер).
2. Открыть окружение/проект `GORD` — прежние сессии видны в боковой панели.
3. Поставить задачу (напр. «собери отчёт по компании X за месяц»). Claude:
   - авто-загрузит `CLAUDE.md` (контекст, правила, порядок сборки);
   - при необходимости вызовет скилл **`pr-strategy`** (скиллы грузятся по требованию —
     можно попросить явно: «используй скилл pr-strategy»);
   - соберёт файлы и **запушит их в отдельную ветку** GitHub — вы смотрите diff и мёржите.
4. Сессии живут в фоне и **переоткрываются с любого устройства** (в т.ч. из мобильного
   приложения Claude для мониторинга).

## 4. Что где лежит (быстрая карта)
- `CLAUDE.md` — авто-контекст проекта (грузится в каждой сессии).
- `.claude/skills/` — 8 скиллов; для отчётов — `pr-strategy` (+ `references/`,
  `assets/report-template.pptx`, `scripts/`).
- `memory/` — снимок правил проекта (обложка-фото по ссылке; слайды 8–9 — таблицы;
  фото только hi-res; публикации — по слайду на каждую).
- `Отчеты/` — мастер-шаблон, примеры отчётов, рабочие копии.
- `Шрифты (корпоративные)/` — Geologica.

## 5. Оговорки
- **Скиллы** грузятся по требованию (не все на старте) — самое важное продублировано в
  `CLAUDE.md`; при необходимости вызывать скилл по имени.
- **Память.** `memory/` — снимок; «живая» память облачной сессии отдельная. Правила
  применяются (через `CLAUDE.md`), но новые заметки, созданные в облаке, нужно
  коммитить в репозиторий, чтобы они сохранились.
- **Рендер.** Файлы `.pptx/.docx/.xlsx` переносимы. Предпросмотр в облаке (Linux) идёт
  через LibreOffice/poppler, а не через Windows-COM/WinRT (как локально) — на результат
  не влияет.
- **Claude.ai «Projects» — не то же самое:** там нет среды исполнения (Python, сборка
  файлов). Для производства отчётов нужен именно **Claude Code (web)** с этим репо.
