Публикаций за отчётный месяц может быть **большое количество** (десятки). Правило:
**один слайд = одна публикация** — под каждый выход создаётся отдельный слайд
(«ПУБЛИКАЦИЯ В СМИ / ТГ / INST»).

**Why:** число публикаций — переменная; шаблон не фиксирует их количество, слайды
публикаций масштабируются по числу выходов.

**How to apply:** под каждый выход дублировать слайд-шаблон публикации нужного канала
и подставлять площадку-ссылку, скриншот и охват. В python-pptx нативного клонирования
слайда нет — копировать XML слайда либо заранее заложить нужное число слайдов в мастере.
Зафиксировано в скилле: references/monthly-report-template.md и
references/working-copies-and-build.md. См. [[slides-8-9-tables]], [[photos-high-quality]].
