# GORD PR AGENCY — рабочий репозиторий

Рабочие материалы бутикового PR-агентства **GORD**: методология (скиллы), фирменный
стандарт оформления, мастер-шаблон отчёта и генераторы. Открывается как проект Claude
Code — скиллы и правила ниже подхватываются автоматически.

## Скиллы (`.claude/skills/`, загружаются автоматически)
8 скиллов по услугам агентства. Главный для отчётов и презентаций — **`pr-strategy`**,
у него есть справочные материалы:
- `references/gord-visual-identity.md` — визуальный стандарт (палитра, шрифт Geologica,
  вотермарк, сетка, чек-лист).
- `references/monthly-report-template.md` — инвентарь слайдов мастера и конвенции заполнения.
- `references/working-copies-and-build.md` — рабочие документы слайдов 7–9 и технические
  правила сборки.
- `assets/report-template.pptx` — **канонический мастер-шаблон** (16 слайдов, 16:9).
- `scripts/build_report.py` — генератор-черновик (приоритет у мастер-шаблона).

## Правила проекта (`memory/` — читать перед сборкой отчётов)
Снимок памяти с durable-правилами: `MEMORY.md` — индекс, далее:
- фото BRAND на обложке берётся по ссылке;
- слайды 8–9 — таблицы по ссылкам (Google Drive), не фото;
- **все фото в отчёте — только высокого разрешения** (без мелких превью/апскейла);
- публикаций может быть много — **один слайд = одна публикация**.

## Как собирать отчёт (кратко)
Копия мастер-шаблона → замена плейсхолдеров (`XXX`, серые боксы, синие ссылки, `—`) →
вставка изображений/таблиц «по размеру» (документы/таблицы — contain, фото — cover) →
дублирование слайдов публикаций и строк AVE/OTS по объёму. Детали и входные данные —
в `references/monthly-report-template.md`.

## Технические заметки (среда)
- Python-библиотеки: `pip install -r requirements.txt` (python-pptx, openpyxl,
  python-docx, Pillow, XlsxWriter) — кроссплатформенно, генерируют pptx/docx/xlsx.
- **Корпоративный шрифт Geologica** — `Шрифты (корпоративные)/Geologica-VariableFont_*.ttf`.
  Перед рендером установить в систему (в Linux: скопировать в `~/.local/share/fonts` +
  `fc-cache`), иначе подставится другой шрифт.
- **Рендер/предпросмотр зависит от ОС.** Windows (локально): PowerPoint COM (pptx→png) и
  WinRT `Windows.Data.Pdf` (pdf→png). Linux/облако: использовать `libreoffice --headless
  --convert-to pdf/png` и poppler (`pdftoppm`) вместо COM/WinRT. Сами файлы pptx/docx/xlsx
  переносимы; отличается только тулинг предпросмотра.
