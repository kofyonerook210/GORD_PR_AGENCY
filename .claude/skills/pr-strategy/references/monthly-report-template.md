# Ежемесячный PR-отчёт GORD — структура и шаблон

> **Собираем на базе мастер-шаблона** [../assets/report-template.pptx](../assets/report-template.pptx)
> (16 слайдов, канва 10″×5.625″, все типы страниц с плейсхолдерами). Рабочий процесс:
> копируем мастер → заменяем плейсхолдеры (`XXX`, серые боксы, синие ссылки, `—`) →
> вставляем реальные изображения/таблицы → дублируем слайды-таблицы и публикации по
> числу каналов и выходов. НЕ пересобираем с нуля в коде — мастер собран агентством
> вручную и является источником истины.

Документ описывает **этапность работ**, **какие данные нужны на входе** и **инвентарь
слайдов мастера**. Визуальные константы — в [gord-visual-identity.md](gord-visual-identity.md).

Тип документа по методологии агентства: это отчётный артефакт услуги
**PR-сопровождение** (этап «Мониторинг, отчётность, корректировка»), оформленный в
метрике `публикация → охват → PR Value`, которую задаёт [pr-strategy](../SKILL.md).

## A. Что нужно собрать на входе (данные заказчика/за месяц)

Прежде чем верстать, собери и проверь фактуру. Отчёт — это витрина уже сделанной
работы, поэтому качество данных определяет всё.

**1. Шапка проекта**
- Название клиента/бренда (лат. и кир. написание), для строки `GORD AGENCY x BRAND`.
- Отчётный период: «МЕСЯЦ ГОД».
- Год для колонтитулов, `SINCE YYYY` (год старта сотрудничества).
- Фоновое фото объекта/продукта клиента (для обложки и страниц-разделителей).

**2. Сводные KPI за месяц** (страница «Результаты»)
- Общий охват за месяц (число).
- «10% от охвата в СМИ» (расчётный показатель качества охвата).
- **PR Value / Выгода** в рублях — эквивалент рекламного бюджета.
- Число упоминаний во всех медиа; разбивка: публикаций в СМИ, публикаций в ТГ,
  упоминаний в INST и др.

**3. Реестр выходов** — таблица по каждой публикации:
`№ | Название площадки | Ссылка | Формат | AVE | OTS`.
Форматы из эталона: `экспертный материал`, `дайджест`, `пост`, `сторис`,
`рилс (с упоминанием в описании)`. Разбивается на 3 блока-раздела: **СМИ**, **ТГ**,
**INST/TT/Max**. AVE — стоимость размещения, OTS — потенциальный охват контакта.

**4. Список выполненных PR-задач за месяц** — маркированный список (см. эталон:
пресс-релиз, пресс-пакет, сбор и рассылка по СМИ, сбор и приглашение инфлюенсеров,
передача броней, ведение таблиц броней, согласование условий, коммуникация с
блогерами/журналистами, питчинг подкастов и YouTube, список партнёров, экспертные
тексты, еженедельные созвоны, резюме недели, итоговый отчёт и т.д.).

**5. Контентные доказательства** — по каждой значимой публикации:
- скриншот материала (СМИ — веб-карточка статьи; INST/TT — скрин телефона/сторис);
- источник и кликабельная ссылка;
- охват этой конкретной публикации;
- полные тексты экспертных материалов (если писались агентством).

## B. Этапность сборки отчёта

1. **Сбор и сверка данных** (раздел A). Проверить суммы: KPI на странице
   «Результаты» должны сходиться с суммами по таблицам AVE/OTS.
2. **Заполнение шаблона** постранично (раздел C) в фирменном стиле.
3. **Внутренняя проверка:** единый период во всех колонтитулах (частая ошибка
   эталона — на дашборде осталась метка «ДЕКАБРЬ 2025» при майском отчёте: **не
   копировать чужой период, обновлять все даты**); рабочие ссылки; читаемость
   белого текста поверх фото (оверлей 40–60%); разрядка чисел неразрывным пробелом.
4. **Финализация:** обложка + финальный красный слайд, экспорт в PDF/pptx.

## C. Мастер-шаблон: инвентарь слайдов и заполнение

Всё строим на [../assets/report-template.pptx](../assets/report-template.pptx).

**Конвенции плейсхолдеров:**
- `XXX` — заменить текстом (бренд, период, тема материала).
- **Серый бокс `#A6A6A6`** с курсивным хинтом внутри — вставить изображение
  (фото/скриншот/таблицу/road map), затем убрать хинт.
- Синяя подчёркнутая `Наименование площадки` — заменить названием площадки и повесить
  гиперссылку.
- `—` в KPI/`ОХВАТ` — заменить числом (разрядка неразрывным пробелом).

**Типографика (канва 10″×5.625″, всё — Geologica):** заголовок обложки 40 pt **Bold**;
период обложки 13 pt ExtraLight; наименования слайдов 20–22 pt Regular UPPER;
подзаголовки 13 pt ExtraLight UPPER; KPI-числа 26–28 pt Bold, подписи двухуровневые
(1-я строка 12–13 pt Regular UPPER, 2-я 12–13 pt ExtraLight sentence-case); колонтитулы
6–9 pt ExtraLight; `ОХВАТ:` 11 pt Regular + значение 11 pt Bold.

**Инвентарь (порядок слайдов в мастере):**
1. **Обложка** — чёрный фон (место под фото); красный жирный `GORD AGENCY x XXX`,
   строчная «x»; период `XXX 2026 – XXX 2026`; углы: год (в.правый), `SINCE 2022`
   (н.правый); хинт `[ МЕСТО ПОД ФОТО ]` по центру снизу.
2. **Результаты** — бежевый `#CDB996`; `РЕЗУЛЬТАТЫ` белый; слева 3 KPI (линейка +
   двухуровневая подпись: ОБЩИЙ ОХВАТ / 10% ОТ ОХВАТА / ВЫГОДА PR-value); справа
   **серый бокс** (место под фото) с 4 мини-KPI поверх (упоминаний во всех медиа;
   публикаций в СМИ; в ТГ; в INST); углы: `XXX 2026` (в.левый = период),
   `GORDPR.RU` (в.правый), `GORD AGENCY` (н.левый).
3. **Выполненные PR-задачи** — чёрный, **без фото**; заголовок + подзаголовок
   (`ЛИЧНЫЕ БРЕНДЫ` либо `ПРОЕКТ «XXX»`); маркированный список (буллеты `XXX`);
   **вотермарк белый**; `GORD AGENCY` в.левый. Дублируется по числу разрезов.
4. **Публикация в СМИ** — чёрный; `ПУБЛИКАЦИЯ В СМИ: Наименование площадки` (синяя
   ссылка); серый бокс под скриншот; `ОХВАТ: —` н.левый; вотермарк красный.
5. **Написание пресс-релиза: XXX** — серый бокс → вставляется лист пресс-релиза.
6. **Составление ROAD MAP: XXX** — широкий серый бокс → вставляется таблица road map.
7. **Составление списка блогеров** — широкий серый бокс → вставляется таблица блогеров.
   > Структура рабочих документов слайдов 5–7 (пресс-релиз / road map / список блогеров),
   > конвенции заполнения и вставки — в
   > [working-copies-and-build.md](working-copies-and-build.md). Под серым боксом слайда
   > road map в мастере лежит остаточный эталонный скрин — удалять перед вставкой.
8. **AVE/OTS В СМИ / В ТГ / В INST** — чёрный; таблица (шапка `#D5D5D5`:
   `№ · Название · Ссылка · Формат · AVE · OTS`, ~8 строк); `ОХВАТ: —` н.левый;
   вотермарк красный. Строки/страницы добавляются по объёму.
9. **Публикация в СМИ / ТГ / INST** (с серым фото-боксом) — **один слайд = одна
   публикация**. Публикаций может быть **много** (десятки за месяц) — под каждую
   создаётся отдельный слайд (дублируется шаблон публикации соответствующего канала,
   меняются площадка-ссылка, скриншот и охват). Для соцсетей в бокс ставится
   вертикальный скриншот телефона.
10. **Финал** — красный `#D72410`; белый `GORD AGENCY` + `БУТИКОВОЕ КОММУНИКАЦИОННОЕ
    АГЕНТСТВО`; год н.правый.

**Масштабирование:** число слайдов — переменная. Дублируй слайды публикаций **под
каждый выход** (их может быть большое количество) и строки/страницы таблиц AVE/OTS по
объёму; удаляй типы, которых в месяце не было (напр. road map). Колонтитул-год — в
нижнем-левом углу (1.5 см от края), кроме дашборда; нумерации слайдов нет.

## D. Логика и выводы (для переноса на другую компанию)

- Отчёт держится на **доказательности**: каждая цифра из сводки подтверждается
  строкой в таблице и скриншотом. При сборке для нового клиента сохраняй эту цепочку
  `сводка → реестр → скриншот`, иначе отчёт превращается в набор картинок.
- **Метрика ценности — PR Value/AVE/OTS**, а не просто число публикаций: это прямое
  выражение принципа агентства «PR вместо рекламного бюджета».
- **Структура — константа, объём — переменная.** Меняется количество строк в
  таблицах и число страниц-публикаций; последовательность блоков (обложка →
  результаты → задачи → таблицы → тексты → скрины СМИ → скрины соцсетей → финал)
  остаётся неизменной.
- **Что потребуется от нового клиента до старта вёрстки:** брендовое написание
  названия, период, фон-фото объекта, сводные KPI, реестр выходов с AVE/OTS,
  список задач за месяц, скриншоты и охваты по каждой публикации, тексты экспертных
  материалов.
